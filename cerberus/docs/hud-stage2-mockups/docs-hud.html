IOC Report — OPS-2847 (TA558 Attribution)

Summary

Three outbound DNS events targeting *.malicious-cdn[.]com were correlated to a known TA558 phishing campaign. Two IPs have prior attribution; the third is new but shares the same ASN and /24 block.

Severity escalated to HIGH. Subnet blocked. L2 assigned.

Indicators of Compromise

Indicator Type Attribution Confidence
34.82.47.211 IP TA558 (known) High
34.82.47.219 IP TA558 (known) High
34.82.47.223 IP TA558 (inferred) Medium

Timeline

  • 13:38 UTC — First DNS event detected by SIEM
  • 14:09 UTC — JARVIS correlation complete
  • 14:12 UTC — Escalated to HIGH, assigned to Marcus L.
  • 14:22 UTC — Blocklist push deployed (34.82.47.192/26)

Recommended Actions

  1. Notify ASN owner (AS15169) via abuse report within 24h
  2. Review all outbound DNS logs for malicious-cdn[.]com variants
  3. Update threat register with TA558 TTP mapping
  4. Consider expanding block to full /24 if activity continues
